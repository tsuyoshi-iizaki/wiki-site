# マネジメント勉強まとめ

## 概要

マネジメントの基礎理論と実践をセルフ/チームの2軸で整理した個人ノート。テイラーの科学的管理法から現代の最適化思考への変遷を踏まえ、環境・プロセス・リソース・感情の「重要四元素」フレームワークでマネジメントの全体像を構造化している。

## 主要な主張

- **マネージャー = 管理者ではなく最適化者**。管理は手段の一部にすぎない
- **テイラーの科学的管理法**: 標準作業時間 → ノルマ概念の誕生 → 効率主義への反発 → 最適化への転換
- **重要四元素**: 環境・プロセス・リソース・感情をセルフ/チームの2軸で展開する
- **セルフマネジメント4要素**: 優先順位と期限 / 重点思考（取捨選択） / ルーティーン / 空気を読む力
- **チームマネジメント4要素**: 集団→チーム化 / 熱・理・情 / 人材プロファイル / 「伝わる」コミュニケーション
- ミスコミュニケーション防止には作業目的・必要工程・期待アウトプットの3点を伝える

## メモ

- 「興味を持つ努力ができる & 行動できる人間」が個人的なマネージャー像
- 一時的な最適化（モチベーションを上げるだけ）と持続的な最適化の区別が重要
- 人材プロファイルではタスクに上下をつけないリスペクトが必要
