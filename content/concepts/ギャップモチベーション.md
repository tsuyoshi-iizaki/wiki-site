# ギャップモチベーション

## 定義

現状と目標の間のギャップ（差）を認識したとき、人は「やる気」に依存せず自然とそのギャップを埋めようとする。この自然な衝動を活用するモチベーション理論。

## 仕組み

3つのメカニズムと1つの設定ツールで構成される。

### 1. ギャップモチベーション（基本原理）

期日のあるタスクと「終わらせないと迷惑がかかる」という認識が組み合わさると、やる気の有無に関係なく行動が生まれる。

### 2. 未来記憶

強い感情を伴って想像した「こうなりたい未来」。五感（イメージ・音声・感情・動作）を明確にし、毎日繰り返し想像することで行動を駆動する。

**ポイント:**
- 曖昧な目標（「南の島でスローライフ」）は機能しない
- 達成できそうと感じられる具体性が必要
- 「こうなりたくない未来」の想像も有効（ダルビッシュ式）
- 長期目標は短期目標に分解して適用する

### 3. 過去記憶

過去の成功・失敗体験が自己効力感の根拠となる。成功は「自分はできる」の証明に、失敗は「次はもっと努力が必要」の学びになる。

**最強ループ:** 過去記憶で自信 → 未来記憶で次の目標 → 達成 → 新たな過去記憶 → 繰り返し

### 4. 自分設定理論

目標達成に必要な「自分像」を設定し、その設定に従って行動する。ハードルは低くから始める。

## 重要性

「やる気が出ない」を根本から解消するフレームワーク。感情や意志力に頼らず、構造的に行動を生み出せる。[[マネジメント]]のセルフマネジメント（ルーティーン構築、重点思考）と組み合わせることで、個人の生産性を体系的に高められる。

> [!key-insight] 過程を喜ぶ
> 結果だけを喜ぶと、失敗時にループが崩壊する。「こういう努力をしたからこういう結果になった」と過程を含めて喜ぶことで、脳が努力と成果の因果関係を学習し、努力に前向きになれる。

## 具体例

- マラソン2位 → 1位の未来記憶 → 早朝練習 → 1位達成
- 基本情報技術者取得 + 評価向上 → 過去記憶として「この努力量でこの成果」が証明される
- 40歳でスキルがない未来を想像 → 回避のため今行動する（ダルビッシュ式）
